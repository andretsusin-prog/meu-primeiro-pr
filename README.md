# meu-primeiro-pr

Repositório de prática para aprender o fluxo de pull requests no GitHub.

## Objetivo

Praticar o ciclo completo de contribuição no GitHub:

- Criar uma branch
- Fazer uma alteração pequena e segura
- Abrir um Pull Request
- Revisar e fazer o merge
